# SpecTrail v0.9.0

SpecTrail v0.9.0 is the first installable bounded-Agent release of the
local-first, source-grounded ReqIR extraction and review workflow.

## Highlights

- Parse Markdown, DOCX, and text-based PDF inputs into canonical blocks and a
  versioned Evidence index.
- Ground requirements to exact text ranges, PDF page regions, and supported
  DOCX/PDF table cells, including validated merged-cell topology.
- Run deterministic fixed orchestration or opt into bounded Agent orchestration
  with typed decisions, allowlisted tools, explicit budgets, and Planner-owned
  retry decisions.
- Observe recoverable extraction failures as Planner observations while keeping
  transaction, identity, trace, policy, and unexpected failures fail-closed.
- Audit Agent runs through immutable event and attempt artifacts, a
  generation-bound read-only API, and the Review UI trace panel.
- Review, approve, reject, restore, or edit requirements with generation and
  revision guards before exporting ReqIR JSON and Excel.
- Gate extraction quality, Agent behavior, real-world PDF parsing, frontend
  behavior, and visual acceptance in CI.

## Installation

Download `spectrail-0.9.0-py3-none-any.whl` from the GitHub Release and install
it into a new Python 3.10+ virtual environment:

```bash
python -m venv .venv
.venv/bin/python -m pip install spectrail-0.9.0-py3-none-any.whl
```

The wheel contains the default mock extraction fixture and all bundled Agent
recorded-planner fixtures. Fixed/mock and Agent/recorded runs therefore do not
depend on a source checkout.

## Compatibility and boundaries

- Python 3.10 or newer is required.
- The fixed pipeline remains the default; Agent orchestration is explicit.
- Recorded fixtures are deterministic regression inputs tied to their source
  document and are not substitutes for arbitrary live documents.
- Live extraction and live Agent planning require an explicitly configured
  OpenAI-compatible provider.
- Scanned PDFs, OCR, image/chart understanding, authentication, persistent
  database storage, async queues, and multi-document tasks are not included.
- Generated requirements remain subject to human review before downstream use.

## Post-release validation

The next activity is a 10–20 document fixed-vs-Agent real-world study covering
Markdown, DOCX, PDF, tables, long documents, and poorly structured inputs. It
will report success, requirement quality, Evidence grounding, retries,
planner/tool sequences, token usage, elapsed time, failure reasons, and whether
Agent orchestration adds measurable value. This study is evaluation work, not a
v0.10 feature branch.
