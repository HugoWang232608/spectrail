# SpecTrail v0.9.1

SpecTrail v0.9.1 is a correctness release for live Agent orchestration and
real-world PDF Evidence validation.

## Fixed

- Live OpenAI-compatible Planner and extraction requests now default to
  `response_format={"type":"json_object"}` while preserving an explicitly
  configured response format.
- The Planner prompt publishes exact invoke and finish object shapes and
  explicitly rejects observed aliases such as a tool name in `action` or
  `args` in place of `arguments`.
- The extraction prompt requires exactly one top-level `{"items":[...]}` object
  and forbids a bare array, Markdown fence, or prose.
- Planner and extraction prompt versions were advanced, with all bundled
  recorded fixture identities regenerated.
- PDF Evidence consistency now distinguishes expected-but-unavailable
  `table_cell` capability from actual published table Evidence. This allows the
  297-page NASA Systems Engineering Handbook to validate without weakening the
  invariant for real table IDs, rows, or cells.

## Verification

- Full Python suite: 584 passed, 1 skipped.
- Complete NASA handbook: 6,735 blocks, 297 pages, 104 accepted tables, Evidence
  consistency passed.
- Live SHA-locked Markdown rerun: fixed completed with warnings and 7/7 grounded
  requirements; Agent inspected a partial failure, changed chunking arguments,
  retried, and completed with 12/12 grounded requirements.

The single paired live case verifies the repaired production path. It is not a
claim that Agent mode is generally superior; the remaining corpus still needs
paired execution and human semantic review.
